# 능선 · Neungseon

실제 고도 데이터로 만든 **북한산 백운대(836m)** 가을 산길을 걷는 웹 산행 게임이에요.
브라우저에서 바로 플레이할 수 있어요: https://neungseon.com/

- 백운대탐방지원센터 → 하루재 → 백운산장 → 위문 → 백운대 정상, 편도 약 2.6km
- 인사·쉬기·물 마시기·숨 고르기·사진, 1인칭 시점, 화면 정리(H)
- 한국어 · English · 日本語 · 中文
- PC(키보드·마우스)와 휴대폰(가상 조이스틱) 모두 지원

지형 고도: AWS Terrain Tiles (Mapzen Terrarium, SRTM 등 공개 DEM). 탐방로는 주요 지점을 지형에 맞춰 이은 근사치예요.

A small web hiking game on Bukhansan's Baegundae trail, built from real elevation data.
